# Sri Sri Kotthama Thalli Home Bakery — Static Website

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/bakery-poster.jpeg` — supplied bakery poster used in the hero section

## Run locally
Open `index.html` in a web browser. No build tools or server are required.

## Publish
Upload the entire folder to any static hosting service (for example GitHub Pages, Netlify, or a regular web host). Keep the `assets` folder beside `index.html`.
